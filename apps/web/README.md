# apps/web

Next.js (App Router) + TypeScript + Tailwind. Owner dashboard (Phase 7) and the browser
test-call page (Phase 1).

From the repo root:

- `make web` starts the dev server on http://localhost:3000
- `make lint` runs ESLint and the TypeScript check (along with the Python linters)

Directly: `pnpm dev`, `pnpm lint`, `pnpm typecheck`, `pnpm build`.
